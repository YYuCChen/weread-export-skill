# playbook —— 微信读书导出：症状 → 判据 → 修法

> 什么时候看：导出出现异常、核验不达标，或想理解某个机制时，按「症状」检索本文。
> 每条三要素：**症状**（现象）/ **判据**（怎么确认命中）/ **修法**（脚本落点）。
> 全部来自实机实测（含《智能：AI时代的商业、组织与战略的本质》一书的完整导出与核验），以修复态为准。

## 怎么用

1. 先看症状（0 章秒退 / 字数偏低 / 乱码 / 图片缺失 / 核验未达标……）。
2. 用「判据」确认命中（多数判据可在核验报告与脚本输出里直接看到）。
3. 按「修法」处理；「脚本落点」给出包内具体文件与函数。
4. 下方「条目索引」可按关键词先定位到条目号，再跳转细读。

## 选择器

### P01 翻页控件过时 → 0 章秒退

- **症状**：脚本很快退出，只输出「无新章节，导出完成」，0 章。
- **判据**：新版阅读器不再渲染 `button.readerFooter_button`；翻页控件 = `button.renderTarget_pager_button`（文本「下一页」）。
- **修法**：`weread_nav.advance_reader` 依次尝试新 / 旧选择器，只点「下一页」，绝不用方向键、不点页面中央。

### P02 标题选择器兼容

- **症状**：章节标题读不出来（空标题），或顶部标题不更新。
- **判据**：新旧两个顶栏标题元素：`.readerTopBar_title_chapter`（旧）/ `.renderTargetPageInfo_header_chapterTitle`（新）。
- **修法**：`weread_nav._title` 双选择器兼容读取（`?.textContent?.trim() || ''`）。

### P03 目录首项与浮层

- **症状**：相邻章节来回振荡、重复抓取；选了目录首项后目录浮层不关闭。
- **判据**：用「点页面中央 + ArrowRight」翻页会振荡；目录浮层在选择当前项后可能保持打开。
- **修法**：`weread_nav.goto_first_chapter` 原生点击目录首项；`close_catalog_if_reader_hidden` 兜底关闭浮层；翻页只用显式控件。

## 坐标系

### P04 真坐标反交织（根因级）

- **症状**：标题字被织进正文行（如「A理解I发这一展点…」）。
- **判据**：`fillText` 收到的是局部坐标——不同文本框各自 `translate` 后都从 (0, y) 起画。
- **修法**：`weread_capture.CANVAS_HOOK` 用 `ctx.getTransform()` 乘变换矩阵，再加画布 `getBoundingClientRect()`，得到真实页面坐标。

### P05 双页区间拆分

- **症状**：标题页与正文页同屏时，两页字符按 x 交织进同一行。
- **判据**：y 重置点检测在同屏两个 canvas 时失效。
- **修法**：`weread_text.split_spread_by_canvas` 按 canvas 物理 x 区间分桶；单 canvas 回退 `split_spread` 的 y 重置法。

## 字号切章

### P06 标题粘连与换行拆分

- **症状**：小节标题粘在段首；章节标题在正文里重复出现。
- **判据**：大字号标题换行成多行，段落合并后与正文首句粘连，按行判断失效。
- **修法**：`weread_chapter.split_heading_prefix` 在合并结果上做标题前缀匹配，拆出标题单独成段；与章节同名则丢弃（`render_chapter_md`）。

### P07 扉页切章与归一化

- **症状**：新章节扉页被算进上一章（章节内容消失）；或开出重名重复章。
- **判据**：阅读器顶栏标题滞后一页更新；切章后顶栏翻到同名标题时可能只差空格（"AI OS" vs "AIOS"）。
- **修法**：`weread_chapter.find_title_line` 按字号识别扉页（标题 ≥1.25× 正文字号且前缀命中目录标题）切章；标题比较一律归一化；切章分支不得提前 break。

## 判重阈值

### P08 3-gram 阈值 0.85

- **症状**：长章节尾页反复重放 → 字数虚高；或阈值过低误杀边界页 → 字数偏低。
- **判据**：整页重放 ≈ 3-gram 重合度 ~100%；0.6 会误杀「大部分旧内容、末尾带新句子」的边界页。
- **修法**：`weread_text.text_already_seen` 阈值取 0.85（只丢几乎完全重复的整页重放）。

## 行内双写

### P09 折叠 A+A 与逐字叠印 AABB

- **症状**：同一段文字出现两遍（实测版权页 161 字 ↔ 322 字）。
- **判据**：阅读器偶发把同一行画两遍（A+A），或逐字叠印（AABB）。
- **修法**：`weread_text.collapse_doubled_line` 行重建时折叠；后处理 `weread_postprocess.collapse_doubled_lines` 第二道兜底。

## 末行标题

### P10 溢出的末行小标题下移

- **症状**：小节标题落在上一章文件的末尾（下一章的标题跑错章）。
- **判据**：页尾画出的小标题溢出；特征 = 短、无句末标点、无逗号，且下一章首段是正常句子。
- **修法**：`weread_postprocess.move_trailing_headings` 把这类末行移到下一章开头。

## 封面变体

### P11 t9_ 高清封面 + 封面章

- **症状**：封面糊（70×100 缩略图）；或全书缺封面页。
- **判据**：详情接口给 `s_` 前缀缩略图；DOM 是 `t6_`（250×359）；`t9_` = 428×614 高清变体。
- **修法**：`weread_text.best_cover_url` 升级 `t9_` 变体；`weread_postprocess.download_cover` 下载 + `write_cover_chapter` 补「封面」章（网页端封面页是 DOM 简介页，正文通道取不到）。

## 平台字数接口

### P12 chapterInfos + 数字 ID

- **症状**：不知道平台标称字数，无法核对完成度。
- **判据**：平台标称字数网页端不显示；接口 `/web/book/chapterInfos`（bookIds 参数）返回逐章 wordCount；数字 ID 见 `/web/book/readInfo` 响应的 `bookInfo.bookId`。
- **修法**：`preflight.fetch_baseline` 经已登录会话拉取，保存 `<book_dir>/_platform_chapterinfo.json` 供核验对照。

## Typora 内嵌图

### P13 超长 base64 压缩

- **症状**：Typora 打开 Markdown 显示一大段原始文本（用户报「全是乱码」）。
- **判据**：内嵌图单行 base64 过长（201KB 图 ≈ 26.9 万字符），编辑器把 data URI 当普通文本排版。
- **修法**：`make_formats.shrink_for_embedding` 内嵌前把大图压到 ≤18KB（最大 base64 行 ≈1.5 万字符；sips 优先，Pillow 回退）；EPUB / PDF 仍用原图。

### P14 编码判定（前 12000 字节）

- **症状**：怀疑 Markdown「乱码」，但内容本身正常。
- **判据**：Typora 只校验文件**前 12000 字节**的 UTF-8；不通过才退回 jschardet 猜编码（猜错则整篇乱码）。
- **修法**：输出保持纯 UTF-8；排查乱码先排除编码层（前 12000 字节可解码），再怀疑内容层。

### P15 交付前渲染自检

- **症状**：文件「字节合法」但编辑器显示异常。
- **判据**：只校验字节无法证明渲染正确（图是否真的显示为图片）。
- **修法**：交付前用 Chromium 渲染一遍（pandoc → HTML → 截图）；有条件时把 md / epub / pdf 各打开看一遍真实观感。

## 核验基线

### P16 多指标报告

- **症状**：无法判断导出是否完整。
- **判据**：单看「到全书完」不够，需要多指标对照。
- **修法**：`verify_export` 报告 = 平台标称 / 本地字符数 / CJK 数 / 目录条目 / 章节数 / 逐章对照 / 重复检查 / 图片校验 / 末章对照。

### P17 缺口优先排查

- **症状**：正文/平台标称不达标。
- **判据**：先查缺漏或重复，绝不为凑数字复制内容。
- **修法**：按核验报告「平台有、本地缺的章节」→「重复段落组数」→「偏短章节」顺序排查；逐条回源检查。

### P18 测试回归

- **症状**：担心修复引入回归。
- **判据**：46 项导航 / 抓取 / 切章 / 后处理回归（含包级检查）。
- **修法**：改动后跑 `python3 -m pytest scripts/tests -q` 全绿才算过；新发现的坑补回归测试。

## 基础流程与合规

### P19 登录持久化

- **症状**：每次运行都要扫码；或中途跳出登录页。
- **判据**：登录态存在浏览器持久化目录；失效时页面跳转 login。
- **修法**：`weread_common.profile_dir()`（`~/.weread-export/profile/`）持久化；`classify_login_url` 判失效 → 提示扫码重登（不绕过验证码）。

### P20 URL 与 book_id

- **症状**：翻了几章后 URL 变了，被当成新书。
- **判据**：章节切换后 URL 末段 = 基础 ID + 动态章节令牌后缀。
- **修法**：`weread_common.parse_book_id` 截回 24 位稳定前缀（`^[0-9a-f]{17}g[0-9a-f]{6}`）；不匹配回退整段原样。

### P21 空章保留

- **症状**：版权页 / 献词页（只有标题没有正文）整章消失。
- **判据**：`text_len` 为 0 不应自动丢弃。
- **修法**：`weread_text.save_chapter` 空章照存（章节 md 与 raw 记录都保留）。

### P22 英文片段不过滤

- **症状**：英文人名 / 术语变乱码或被切片。
- **判据**：英文以多字符 `fillText` 片段绘制（如 `Palan` + `ti` + `r`），过滤 ASCII 片段会破坏。
- **修法**：`weread_text.chars_to_lines` 只丢空白片段，保留多字符拉丁片段。

### P23 上下文销毁重试

- **症状**：导航过程中报 `Execution context was destroyed`。
- **判据**：页面导航会销毁 JavaScript 执行上下文。
- **修法**：`weread_nav.wait_stable` 只对明确的 navigation / context destroyed 错误做有限重试，并在新上下文重读。

### P24 位图缓存强制重绘

- **症状**：回访过的页面字符缓冲区为空，该页内容静默漏掉。
- **判据**：命中位图缓存时阅读器不产生新的 `fillText` 调用。
- **修法**：`weread_capture.force_repaint` 抖动视口（高度 +1 → 复原）强制完整重绘；虚拟 DOM 通道有内容时绝不重绘。

### P25 目录项装饰清洗

- **症状**：标题判据漏掉（如「AI发展第一阶段」因尾部装饰未剥离而未被识别）。
- **判据**：目录项文本带「+书签」「当前读到 3%」等装饰。
- **修法**：`weread_chapter.clean_catalog_title` 清洗后再归一化，用于标题判据。

## 后处理与图片

### P26 跨章断句合拢

- **症状**：上一章末句没写完、下一章开头接后半句。
- **判据**：章切分按页进行，而句子会跨页。
- **修法**：`weread_postprocess.stitch_chapter_boundaries` 保守合拢（护栏：残句 2~60 字、不以标点开头；溢出的标题不动；搬后下一章仍有正文）。

### P27 图片坐标与校验

- **症状**：图片落错位置；或引用存在但文件失效。
- **判据**：图片要按文档坐标放回正文位置；下载后要校验格式 / 尺寸 / 非零。
- **修法**：`weread_text.render_chapter_md` 渲染时固化位置并把 `{url, file}` 记入 `raw/<nnnn>.json`（下载名单）；`download_images` 8 线程补齐；`verify_export` 查失效引用与损坏图片。

### P28 --postprocess 重跑后处理

- **症状**：想调整后处理但不想重爬整本。
- **判据**：后处理与主流程共用同一组函数（同一份实现）。
- **修法**：`python3 export_precise.py --postprocess <book_id>` 对已抓目录重跑并重建合并稿。

### P29 自包含输出目录

- **症状**：交付物缺图 / 路径断裂。
- **判据**：输出必须是自包含目录（md + images/ + chapters/ + raw/ + 目录清单），合并稿与 images/ 同级。
- **修法**：`weread_postprocess.build_merged_md` 把合并稿放在图片同级目录；三格式转换时图片全部内嵌。

### P30 三格式生成通道

- **症状**：没有 EPUB / PDF 工具链。
- **判据**：零额外安装即可产出三格式。
- **修法**：`make_formats` = pandoc 出 EPUB（`--toc`）+ pandoc 出单文件 HTML（`--embed-resources`）→ 本机 Chromium `page.pdf()` 打印；Markdown 侧 base64 内嵌（大图先压缩）。
